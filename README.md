# Deep Field

A calm, dark theme for the Claude desktop and mobile apps, inspired by deep-field telescope images: thousands of faint, distant galaxies on near-black space. The art is atmosphere; text always stays easy to read.

- **Palette:** near-black blue base (`#05070D`), deep navy panels (`#0B1020`), soft starlight text (`#E6E9F2`), cool gray-blue secondary text, and a violet accent (`#8B6CF0`) for links, selection, toggles and focus rings.
- **Backdrop:** an original, generated starfield (no image files) with small gold and red galaxy smudges, a few tiny spirals, faint constellations near the edges, and a darker vignette behind the message column.
- **Smoked-glass side panels:** the sidebar and the right panel are frosted so the field shows faintly through.
- **Motion:** a very slow drift of the field, a faint "signal" galaxy that pulses while Claude is working, and a brief twinkle near the input box when a response finishes. All animation stops when your system's reduced-motion setting is on.

The theme is dark-only. The terminal and editor extensions don't draw themes.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install deep-field --marketplace jaddboy/deep-field-theme
```

Answer `y` to add the marketplace, then pick a scope (user scope makes it apply everywhere, including the desktop app's Code tab).

From a shell:

```
claude plugin install deep-field --marketplace jaddboy/deep-field-theme
```

In the desktop app: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `jaddboy/deep-field-theme`, then **Add plugin**.
